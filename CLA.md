## How to accept

Include this line in the description of your first pull request, with your real name:

```
I have read CLA.md and I accept the Rhapto Individual Contributor License Agreement.
```

and sign your commits off:

```
git commit -s -m "your message"
```

which appends `Signed-off-by: Your Name <your@email>`. One acceptance covers all your future
contributions.

If your employer owns rights in your work, ask before contributing — see section 4.2. Contact:
open an issue, or the address in the repository's GitHub profile.
